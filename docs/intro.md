# Colombia Geo API

Colombia Geo API es una API REST diseñada para consultar información geográfica de Colombia de forma sencilla y estructurada.

Puedes utilizarla para consultar **departamentos, ciudades y municipios**, realizar búsquedas y controlar los resultados mediante paginación y ordenamiento.

## ¿Qué puedes hacer?

- Consultar departamentos de Colombia.
- Consultar ciudades y municipios.
- Buscar por nombre o código DANE.
- Utilizar paginación.
- Ordenar resultados.
- Obtener información en formato JSON.

## Base URL

La API estará disponible mediante una URL pública:

```text
https://colombiageoapi.onrender.com/api/v1
```
