# Colombia Geo API

Colombia Geo API is a REST API designed to query geographic information about Colombia in a simple and structured way.

You can use it to query **departments, cities, and municipalities**, perform searches, and control results through pagination and sorting.

## What can you do?

- Query departments of Colombia.
- Query cities and municipalities.
- Search by name or DANE code.
- Use pagination.
- Sort results.
- Get information in JSON format.

## Base URL

The API is available through a public URL:

```text
https://colombiageoapi.onrender.com/api/v1
```
