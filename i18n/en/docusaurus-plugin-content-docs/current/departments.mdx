# Departments

The **Departments** endpoints allow you to retrieve information about the departments of Colombia.

The API provides different ways to access this information: general listing, individual lookup, search, and paginated results.

## List departments

Retrieves all available departments.

### Endpoint

<HttpMethod method="GET">/departments</HttpMethod>

### Parameters

This endpoint does not require any parameters.

### Example

<HttpMethod method="GET">/departments</HttpMethod>

### Response

```json
{
  "data": [
    {
      "id": "54a01b92-6944-4b6a-8461-27e649b8a4dd",
      "daneCode": "91",
      "name": "Amazonas"
    },
    {
      "id": "2a7b4918-065b-418a-842e-024cef8b2ccc",
      "daneCode": "05",
      "name": "Antioquia"
    },
    ...
  ],
  "message": "Departments retrieved successfully",
  "statusCode": 200
}
```

Public read-only endpoints do not require authentication.

## Get department

Retrieves detailed information about a department using its identifier.

### Endpoint

<HttpMethod method="GET">/departments/:id</HttpMethod>


### Parameters

|Parameters|Type|Required |Description                        |
|----------|----|---------|-----------------------------------|
|`id`      |UUID|Sí       |Unique identifier of the department|  

### Example

```http
GET /departments/7b672475-1afc-4617-b118-c2b8efd61709
```

## Paged departments

Retrieves departments using pagination and sorting.

### Endpoint

<HttpMethod method="GET">/departments/paged</HttpMethod>


### Query parameters

| Parameter       | Type    | Required  | Description                  |
| --------------- | ------- | --------- | -----------------------------|
| `page`          | integer | No        | Page number                  | 
| `pageSize`      | integer | No        | Number of items per page     |
| `sortBy`        | string  | No        | Field used for sorting       |
| `sortDirection` | string  | No        | Sort direction: `asc / desc` |


### Example

```text
GET /departments/paged?page=1&pageSize=10&sortBy=name&sortDirection=asc
```

### Response

```json
{
  "data": {
    "items": [
       {
        "id": "7b672475-1afc-4617-b118-c2b8efd61709",
        "daneCode": "08",
        "name": "Atlántico",
        "municipalities": 23,
        "areaKm2": 3386,
        "population": 2865034,
        "flagUrl": "https://raw.githubusercontent.com/gabrielceh/ColombiaFlags/main/departments/08.svg",
        "capital": {
          "id": "c5a23b46-4b7b-4885-a96b-6027dfd285dd",
          "name": "Barranquilla",
          "daneCode": "08001"
        },
        "districts": [
          {
            "districtName": "Distrito Especial, Industrial y Portuario",
            "id": "c5a23b46-4b7b-4885-a96b-6027dfd285dd",
            "name": "Barranquilla",
            "daneCode": "08001"
          }
        ]
      },
      ...
    ],
    "page": 1,
    "pageSize": 10,
    "totalCount": 32,
    "totalPages": 4
  },
  "message": "Departments retrieved successfully",
  "statusCode": 200
}
```

You can use `sortDirection=asc` to sort in ascending order or `sortDirection=desc` to sort in descending order.

### `sortBy`

|Parameter       |Description                         |
|----------------|------------------------------------|
|`name`          |Sort by name                        |
|`daneCode`      |Sort by DANE code                   |
|`population`    |Sort by population                  |
|`area`          |Sort by area                        |
|`municipalities`|sort by number of municipalities    |
