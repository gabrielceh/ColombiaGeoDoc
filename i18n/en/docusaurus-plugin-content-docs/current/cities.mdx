# Cities

The **Cities** endpoints allow you to retrieve information about the cities and municipalities of Colombia, including their department, DANE code, postal code, population, area, capital status, and district characteristics.

---

## Get city by ID

Retrieves detailed information about a city using its unique identifier.

### Endpoint

<HttpMethod method="GET">/cities/:id</HttpMethod>

### Parameters

| Parameter | Type | Required | Description                   |
|-----------|------|----------|-------------------------------|
| `id`      | UUID | Yes      | Unique identifier of the city |

### Example

```http
GET /cities/7b672475-1afc-4617-b118-c2b8efd61709
```

### Respuesta

```json
{

  "data": {
    "id": "c5a23b46-4b7b-4885-a96b-6027dfd285dd",
    "departmentId": "7b672475-1afc-4617-b118-c2b8efd61709",
    "daneCode": "08001",
    "name": "Barranquilla",
    "areaKm2": 166.00,
    "population": 1279344,
    "zipCode": "080001",
    "flagUrl": "https://raw.githubusercontent.com/gabrielceh/ColombiaFlags/main/cities/08/08001.svg",
    "isDepartmentCapital": true,
    "isDistrict": true,
    "districtName": "Distrito Especial, Industrial y Portuario",
    "department": {
      "id": "7b672475-1afc-4617-b118-c2b8efd61709",
      "daneCode": "08",
      "name": "Atlántico"
    }
  },
  "message": "City retrieved successfully",
  "statusCode": 200

}
```

## Get cities by department ID with pagination

Retrieves the cities of a department using pagination and sorting.

### Endpoint

<HttpMethod method="GET">/cities/paged/department/:departmentId</HttpMethod>


### Parameters

| Parameter       | Type    | Required  | Description                          |
| --------------- | ------- | --------- | ------------------------------------ |
|`departmenId`    |UUID     |Sí         |Unique identifier of the department   |
| `page`          | integer | No        | Page number                          |

| `sortBy`        | string  | No        | Field used for sorting               |

```http
GET /cities/paged/department/7b672475-1afc-4617-b118-c2b8efd61709?page=1&pageSize=10&sortBy=name&sortDirection=asc
```

## Search cities

Allows you to search for cities using their name or DANE code.

### Endpoint

<HttpMethod method="GET">/cities/search</HttpMethod>

### Query parameters

|Parameter|Type  |Required |Description           |
|---------|------|---------|----------------------|
|`value`  |string|Yes      |City name or DANE code|

### Example

Search by name:

```http
GET /cities/search?value=Barranquilla&pageSize=20&page=1&sortBy=population&sortDirection=desc
```

Search by DANE code:

```http
GET /cities/search?value=001&pageSize=20&page=1&sortBy=population&sortDirection=desc
```

## Sorting parameters

Paginated endpoints allow you to sort results using sortBy and sortDirection.

### `sortDirection`

| Value  | Description      |
| ------ | ---------------- |
| `asc`  | Ascending order  |
| `desc` | Descending order |


### `sortBy`

The available fields depend on the sorting criteria implemented by each endpoint.

| Parameter    | Description        |
| ------------ | ------------------ |
| `name`       | Sort by name       |
| `daneCode`   | Sort by DANE code  |
| `population` | Sort by population |
| `area`       | Sort by area       |


Example:

```http
GET /cities/paged?page=1&pageSize=10&sortBy=population&sortDirection=desc
```

| Code  | Description                    |

| `200` | Request completed successfully |

| `404` | City or department not found   |
| `429` | Too many requests              |
