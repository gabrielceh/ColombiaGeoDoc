# Getting Started

Making a request to Colombia Geo API is simple. All public endpoints use HTTP and return information in JSON format.

## Base URL

```text
https://colombiageoapi.onrender.com/api/v1
```
Your First Request

To get started, you can retrieve all available departments:

<HttpMethod method="GET">/departments</HttpMethod>

The complete URL would be:

```text
https://colombiageoapi.onrender.com/api/v1/departments
```

## Response

A successful request returns a JSON response with the following structure:

```json
{
  "data": [],
  "message": "Departments retrieved successfully.",
  "statusCode": 200
}
```
